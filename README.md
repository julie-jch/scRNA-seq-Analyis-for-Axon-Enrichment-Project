# scRNA-seq-Analyis-for-Axon-Enrichment-Project
Single cell analysis on Mouse &amp; Human datasets

This repository contains single-cell RNA sequencing (scRNA-seq) datasets and analysis code used to explore axonal guidance pathway enrichment in human and mouse samples of pancreatic ductal adenocarcinoma (PDAC).


Data Sources
Human datasets
Publicly available datasets from two major studies on pancreatic ductal adenocarcinoma were analyzed:

Peng J. et al. Single-cell RNA-seq highlights intra-tumoral heterogeneity and malignant progression in pancreatic ductal adenocarcinoma. Cell Research (2019) 29:725–738.

Chen M.-M. et al. Integrated single-cell and spatial transcriptomics uncover distinct cellular subtypes involved in neural invasion in pancreatic cancer. Cancer Cell (2025) 43:1656–1676.e10.

Mouse datasets
Mouse scRNA-seq data were obtained from the Tuveson Lab, available under GEO accession GSE294749.


Repository Contents
Data/ – contains metadata and processed expression matrices used for downstream analysis.

Code/ – Python scripts for GSEA processing and visualization.


Key Analyses
Differential expression analysis across tumor and stromal subpopulations.

GSEA focused on axonal guidance, neuron projection development, and cell motility pathways.

Cross-species comparison between human and mouse datasets to identify conserved signaling trends.
